# 第七套 RAVEN 设计说明

## 视觉方向

- 纯黑背景与低反射深灰表面，模拟越野车仪表与车间设备。
- 荧光绿只用于连接状态、进度和主要操作；橙色用于骑行模式和高风险参数。
- 使用 1px 分隔线、直角控件、紧凑字号和等宽数字感，避免装饰性卡片堆叠。
- 首页以真实车辆图为第一视觉焦点，状态信息按仪表读数横向组织。
- 详情页保持统一的顶部标题、底部主操作和四栏主导航。

## 功能范围

功能继承完整的 22 页演示链路，包括车辆绑定和重命名、连接、车辆状态、电池、诊断、OTA、服务资料、骑行模式、动力曲线、轮周长、应用更新、语言与本地数据管理。

所有业务行为均由本地 Mock 与 `binsen.raven.v7.*` 存储键驱动，不连接真实硬件。
