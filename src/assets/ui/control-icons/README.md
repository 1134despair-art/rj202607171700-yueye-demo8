# Vehicle control icons

These seven local SVG assets use one 24 x 24 filled vehicle icon family so the
control page keeps a consistent visual weight. The source shapes are from
Material Design Icons 7.4.47 (`@mdi/svg`, Apache-2.0), selected after reviewing
the vehicle-related categories available through Iconfont.

The application renders the files locally through `VehicleControlIcon.vue`.
No external font or CDN is required at runtime.
